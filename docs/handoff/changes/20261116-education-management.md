- **성공 데이터 비교 / 타 부서 거절 / 동시 저장 / A 복귀 결과**:
  - 성공 데이터 비교: 같은 서버 응답으로 A·B의 표 칸·사람 묶음·문구·공무 변경 목록·검사 문구·이력 문구가 일치했다. 수치·CSV는 서버 한 곳에서 계산한다.
  - 타 부서 거절: 타 부서 조회·저장, 다른 소속 사람 끼워 넣기, 미지정 계정, 회수된 부서장 모두 거절되고 기록은 그대로였다.
  - 동시 저장: 두 부서가 실제 Postgres에서 동시에 저장해도 서로의 기록이 보존됐다. 같은 소속의 오래된 화면 저장은 409였다.
  - 기존 전체 화면 병행: 부서 저장 뒤 오래된 전체 저장은 409였고, 다시 조회하면 부서 기록이 포함됐다. 전체 화면이 해제하면 부서 화면에 "해제됨"으로 보이고 공무로 세지 않았다.
  - A 복귀: 기능을 꺼도 기존 보고(`excusedOf`)와 전체 공무 화면에 기록이 남았다. 실제 A/B 전환 경로에서의 복귀 시험은 전환 측에 요청한다.
