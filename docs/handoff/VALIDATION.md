## 자동 배포 차단 근거

루트와 Next 설정의 `git.deploymentEnabled: false`는 [Vercel 공식 Git 설정](https://vercel.com/docs/project-configuration/git-configuration#turning-off-all-automatic-deployments)에 따른다. 현재 운영 프로젝트 자체도 Git 미연결임을 읽기 확인했다. 이 설정은 공유 소스에만 추가했고 기존 운영 브랜치·프로젝트 연결·예약을 바꾸지 않았다. 향후 승인된 배포 과정에서는 적용 범위를 다시 검토한다.
